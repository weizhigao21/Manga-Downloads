# 漫画浏览器

> 项目地址：<https://github.com/weizhigao21/Manga-Downloads>
>
> 当前版本：v1.3.5（更新日志见 [CHANGELOG.md](CHANGELOG.md)）

基于 PySide6 的 wnacg.com（紳士漫畫）桌面浏览器与下载工具，支持分类浏览、关键词搜索、封面缓存、多模式下载与断点续传。

## 功能特性

- **分类浏览**：覆盖网站全部主要分类（同人誌、單行本、韓漫、3D 漫畫、AI 圖集等），切换即抓取该分类最新内容
- **页码跳转**：底部翻页栏页码框可直接输入数字（回车/失焦确认）跳转到任意页，列表浏览与关键词搜索均支持，无需逐页翻找；方向键可微调页码
- **关键词搜索**：回车调用网站搜索接口（`/search/?q=...&f=_all&s=create_time_DESC&syn=yes`），结果与列表页同样支持分页；清空搜索框即返回列表浏览
- **本地数据持久化**：抓取结果写入 SQLite + JSON 缓存，下次启动按当前分类加载最近一页，顺序与网站最新一致，无需等待网络
- **封面本地缓存**：封面图自动下载到 `Config/covers/`，离线也能浏览
- **在线阅读**：点击卡片「阅读」按钮或右键「阅读作品」打开独立阅读窗口，支持**本地优先**、**按需加载**（翻页才取该页）、**边看边缓存**与断点续读
  - **本地优先**：打开时先扫描下载目录，命中即直接读盘、零网络请求；**压缩包模式下载的作品解压后可同样直接阅读**（解压产物与图片模式目录结构一致）
  - **极速本地读取**：已缓存整部作品时翻页是**纯内存查表**——不重扫目录（按目录变更指示做增量判定）、不重复解析详情页（结果进程内缓存）、不重复探测每页张数，相邻页落在同一列表页时复用解析结果；本地已完整却仍缺某页则直接提示，不做无谓联网
  - **页码准确**：按**文件名里的数字**对齐页码（兼容 `1.jpg` / `0001.jpg` / `page_10.jpg`），缺页如实标记并由联网补拉，不会把「第 10 页」错当成第 4 页；联网补拉时按**图片下标 → 网站列表页码**正确换算（网站每列表页约 12 张），超过 13 张的页数也能正常获取
  - **边看边下**：阅读缓存与下载目录**合流**（`Download/[分类标签] 显示名/`），未命中的页在线补拉并写盘；看完的作品天然等同下载完成，之后点「下载」时已缓存部分由断点续传自动跳过，不重复劳动
  - **纯按需加载**：默认**不预取**——打开只加载当前页，只有点「下一页 / 上一页」时才去取那一页，本地已缓存则直接读盘。如需更顺滑的翻页，可在设置中开启「阅读时后台预取相邻页」；预取线程可取消，快速翻页时旧任务立即作废
  - **操作**：方向键 / 空格 / PageUp / PageDown 翻页，点击左右半屏翻页，Home / End 首末页，F 全屏，Esc 关闭；底部显示页码与缓存进度
  - **断点续读**：记录每部作品上次读到哪页，重新打开自动续读（可在设置中关闭）
- **缓存进度圈**：卡片「阅读」按钮左侧的环形进度，**灰底整圈 + 彩色弧按百分比覆盖**（50% 即半圈彩色半圈灰，100% 整圈变绿显示 ✓），圆心显示百分比数字，悬停可看「已缓存 N / M 张」；只读了一部分的作品不显示"已下载"角标，改由该圈表达进度
- **下载管理**：统一任务管理器，实时显示任务 ID、进度与状态；任务列表持久化到 `Config/tasks.json`，重启后恢复历史任务（**已完成任务重启后自动隐藏**；退出时未完成的任务标记为"程序已退出，任务中断"）；**失败任务支持原地重试**（下载管理对话框"重试"按钮；同一作品失败后再次点击下载自动复用原任务，不会重复创建）；**右键任务可删除**（仅移除任务记录，不影响已下载文件，支持多选批量删除）；支持两种下载方式
  - 图片下载：逐张请求图片直链下载，**已下载文件自动跳过（断点续传）**，失败重试不会整部重来
  - 压缩包下载：自动逆向签名直链整包下载并解压（优先调用系统 7z，缺失/失败时回退内置 zipfile）
  - 下载文件夹名为 `[分类标签] 显示名`（翻译名 > 标题自带中文 > 原标题），同名冲突时自动追加作品 ID；下载发起时自动从数据库补全最新翻译名（即使卡片/重试数据较旧）；下载完成（图片下载完毕 / 压缩包解压完毕）后在作品目录生成 `title_info.json`，记录原始名称与翻译名称
- **数据库管理**：设置对话框（左侧导航 + 右侧详情面板）中可直接查看/更改数据库与封面缓存路径、清除封面缓存或清空数据库；数据库管理窗口以**每页 5 条分页**展示记录（上一页/下一页），右上角支持**按标题或 ID 搜索**与**按下载状态筛选**（全部/已下载/未下载），记录表格展示**下载完成时间**（数据库 `downloaded_at` 字段，下载完成时自动写入）；支持**数据库查重**（见下方「查重」小节）；支持**自定义存储路径**（数据库文件与封面缓存目录可分别切换到任意位置，切换时可选择迁移现有数据，无需重启）
- **数据库查重**：数据库管理对话框点击「查重」，按 **封面 / 名称 / 作者** 三个信号扫描重复记录（同一作品被重复上传、原版/汉化并存等场景），树形分组展示并标注命中原因（如"封面相似、名称相同"），可勾选批量删除冗余记录（仅删数据库记录，可选同时清除封面缓存）；封面比对使用 64 位感知哈希（aHash），同一封面即使尺寸/压缩率不同也能命中，哈希增量缓存避免重复扫描重算；计算在后台线程执行并带进度条；数据库自动提取标题方括号中的**作者/社团**信息存入 `author` 字段，供查重与展示使用
- **相似作品提示**：每次抓取/搜索返回一页后，后台自动查询**本地数据库**（不联网）找出同作品重复上传，命中卡片**封面左下角**显示 **≈N** 角标——**橙色**表示有相似可查看，**红色**表示相似记录中已有下载；右键菜单（带颜色圆点提示）「**查看类似作品**」可将列表切换为只显示该作品 + 库内相似记录（顶部提示条可返回）；匹配三信号：名称（含翻译名）、作者、封面（后台下载缺失封面并计算哈希缓存至数据库，复用查重的封面哈希机制）
- **名称翻译**：设置中配置 AI 翻译接口（DeepSeek / OpenAI 兼容，可设链接/模型/Key），右键作品卡片选择「翻译作品名称」即可将标题翻译为简体中文并复制到剪贴板；方括号内容（社团/作者/标签）原样保留、只翻译作品名，标题自带中文翻译（`日文名｜中文名`）或本身就是中文时直接使用、不调 AI；翻译结果持久化到数据库并自动回填显示（重启不丢失），卡片标题显示优先级：AI 翻译名 > 标题自带中文 > 原标题繁简转换，提示显示在左下角状态栏
- **繁简转换**：可选将繁体标题/分类标签自动转为简体
- **温和反爬**：全局请求节流（统一收敛于 `src/net.py`）+ 指数退避重试（429/403/5xx 自动等待）；整包下载使用 TLS/HTTP2 指纹模拟（curl_cffi）绕过 Cloudflare 校验，避免触发站点限流
- **站点结构变化感知**：列表页解析为 0 条时状态栏明确提示"站点结构可能已改版"，而非静默显示"共 0 部"
- **线程安全退出**：关闭窗口/退出程序时统一收尾后台线程（抓取/下载/翻译），请求中断并限时等待，避免 `QThread: Destroyed while thread is still running`；同时终止 7z 等子进程，避免解压中被中断后留下孤儿 `7z.exe`
- **系统托盘驻留**：关闭窗口（点 X）最小化到系统托盘，下载任务在后台继续运行，托盘图标双击/菜单可随时显示主窗口，托盘菜单「退出」才真正结束程序；下载完成时弹出托盘气泡通知（短时间内的多条完成通知自动合并，避免刷屏，可在设置中关闭）
- **单实例运行**：程序已运行时再次启动（如最小化到托盘后重新双击 exe）不会多开窗口，二次启动进程会自动通知已运行实例并退出，主窗口被唤起并置前（基于 QLockFile 判单例 + QLocalServer 命名管道通知，跨平台可靠）
- **稳定布局**：抓取过程中界面不跳动——进度条置于固定宽度容器，状态信息与进度条固定在左下角，翻页按钮组水平居中；窗口显示即按真实宽度渲染多列网格，首次进入不会出现单列错排；刷新、翻页与搜索加载完成后自动回到列表顶部；下载按钮不抢焦点，点击下载不会因按钮状态切换触发页面滑动；下载管理对话框打开时已完成/进行中任务的进度条立即正常显示

## 快速开始

```bash
# 1. 安装依赖（Python 3.10+）
pip install -r requirements.txt

# 2. 启动界面
python run_ui.py

# 3. 仅命令行抓取列表（可选）
python src/wnacg_crawler.py -o list.json
```

## 使用说明

- 顶部搜索框输入关键词后按 **回车** 执行网站搜索，再次回车可翻页；清空搜索框返回列表
- 分类下拉框切换浏览分类；**刷新** 重新抓取当前页；**下载管理** 打开任务列表
- 点击漫画卡片上的 **下载** 按钮加入下载队列（下载完成后卡片左上角显示"已下载"角标）
- 点击卡片上的 **阅读** 按钮（或右键 → **阅读作品**）打开阅读窗口：本地优先读盘，未缓存的页边看边下边缓存；方向键 / 空格翻页，F 全屏，Esc 关闭，重新打开自动续读上次位置
- 卡片「阅读」按钮左侧的**环形进度圈**表示本地缓存进度（灰底 + 彩色弧，50% 即半圈）；想完整收藏某部作品时，看完再点「下载」即可，已缓存部分会自动跳过
- 卡片封面**左下角橙色 ≈N 角标**表示本地数据库存在 N 部相似作品（同作品重复上传）；**右键卡片 → 查看类似作品**可切换为只显示该作品与相似记录，顶部橙色提示条「返回列表」可退出（翻页/刷新/搜索/切分类也会自动退出）
- **设置**对话框为左侧导航 + 右侧详情面板（行为偏好 / 名称翻译 / 项目配置 / 数据库管理）；「数据库管理」面板可直接查看/更改存储路径、清除封面缓存、清空数据库，并可进入完整数据库管理窗口（**每页 5 条**分页记录表格 + 右上角搜索/状态筛选 + **查重**）
- 底部栏左侧显示状态信息与加载进度条，右侧**上一页 / 页码 / 下一页**按钮组居中排列；点击页码框输入数字回车即可**跳页**（列表与搜索均支持），页码未变化时不会重复加载
- 程序为**单实例运行**：最小化到托盘（关闭窗口）后再次双击启动程序，会直接唤起并置前已运行的主窗口，而不会新开一个实例

## 配置说明

项目采用两个配置文件，均在 `Config/` 目录下：

**`Config/Config.json`** — 项目配置（供爬虫与下载功能使用）

| 字段 | 说明 | 默认值 |
| --- | --- | --- |
| `list_url` | 列表页 URL，启动时按此抓取 | `https://www.wnacg.com/albums.html` |
| `Page_number` | 命令行抓取的默认页数 | `20` |
| `Download` | 下载根目录 | `./Download` |
| `Download_workers` | 下载并发数（过高易触发反爬） | `3` |
| `Download_retries` | 失败重试次数 | `3` |
| `Download_mode` | 下载方式：`image` 逐图 / `zip` 整包解压 | `image` |
| `Folder_use_category_label` | 下载文件夹名是否含分类标签 | `true` |
| `convert_traditional_to_simplified` | 是否将繁体转为简体 | `true` |

**`Config/settings.json`** — 应用本地设置

| 字段 | 说明 | 默认值 |
| --- | --- | --- |
| `auto_fetch_on_startup` | 启动时自动抓取最新数据 | `true` |
| `notify_on_download_done` | 下载完成时显示系统托盘通知 | `true` |
| `translate_api_base` | 名称翻译接口地址（OpenAI 兼容） | `https://api.deepseek.com` |
| `translate_model` | 名称翻译模型 | `deepseek-v4-pro` |
| `translate_api_key` | 名称翻译 API Key（仅存本地） | 空 |
| `db_path` | 漫画数据库文件路径（空 = 默认 `Config/comics.db`，可在数据库管理中更改） | 空 |
| `covers_dir` | 封面缓存目录（空 = 默认 `Config/covers`，可在数据库管理中更改） | 空 |
| `reader_prefetch_enabled` | 阅读时后台预取相邻页（默认关闭 = 纯按需，只在翻页时取该页） | `false` |
| `reader_prefetch_ahead` | 向后（下一页方向）预取页数（0-10） | `0` |
| `reader_prefetch_behind` | 向前（上一页方向）预取页数（0-10） | `0` |
| `reader_resume` | 打开作品时续读到上次阅读位置 | `true` |

> 旧版本中保存在 `settings.json` 的繁简转换开关会在启动时自动迁移至 `Config.json`。

**`Config/tasks.json`** — 下载任务持久化（应用运行时自动生成）

记录所有下载任务（ID/名称/链接/状态/进度），重启应用后自动恢复；退出时处于下载中/等待中的任务标记为"程序已退出，任务中断"。

**`Config/comics.db`、`Config/covers/`、`Config/comics_cache.json`** — 漫画记录数据库（含作者字段与封面哈希缓存表）、封面缓存与列表 JSON 缓存（均可通过设置 → 数据库管理 查看/清空，封面哈希在清除封面缓存时一并清除）。**数据库文件与封面缓存目录可自定义**（数据库管理 → 「更改路径」），切换时可选将现有数据迁移到新路径；`comics_cache.json` 列表缓存始终位于 `Config/`。

**`Config/reader.db`** — 在线阅读器元数据（应用运行时自动生成）：图片直链索引缓存（重看时免去重新解析）与每部作品的阅读进度（断点续读）。与 `comics.db` 同目录，跟随「更改路径」配置一并迁移。

## 构建打包（可选）

```bash
pip install pyinstaller
pyinstaller 漫画浏览器.spec
```

或直接双击项目根目录的 **`打包.bat`** 一键打包：自动检查/安装运行依赖与 PyInstaller（含 WorkBuddy 会话内打包的兼容处理）、执行打包并打开产物目录。

打包产物为 onedir 目录 `dist/漫画浏览器/`（主程序 `漫画浏览器.exe` + `_internal/` 依赖），整体拷贝即可分发；onedir 模式启动无需解压归档，打开窗口更快。`Config/`（配置、缓存、封面、数据库）以 exe 所在目录为数据根目录，可直接读写。
